# Changelog

All notable changes to this repository are documented in this file.

## [0.1.0] — 2026-09-10

### Added

- **mcp-sentinel** — MCP policy/audit gateway with hash-chained SQLite log, YAML rules, CLI, and local dashboard
- **agent-control-room** — multi-agent daemon + React dashboard with Claude Code, Cursor, and generic adapters
- **verify-mcp** — verification MCP server with `markdown-links`, `json-schema`, and `secrets` packs
- Root CI, issue/PR templates, Apache-2.0 license, and contributor docs
