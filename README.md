# pet-projects

Open-source **AI agent tooling** experiments. Each subdirectory is its own project (and its own git repo when published).

| Project | What it is |
|---------|------------|
| [mcp-sentinel](./mcp-sentinel) | MCP observability & policy gateway — proxy, hash-chained audit log, YAML policy, local dashboard |
| [agent-control-room](./agent-control-room) | Multi-agent session control plane — kanban, approvals, diff preview, git rollback |
| [verify-mcp](./verify-mcp) | Verification-as-a-tool MCP server — markdown links, JSON Schema, secrets packs |

All projects are TypeScript / Node.js, Apache-2.0, English docs, no telemetry by default.

Replace `YOUR_GITHUB` in each `package.json` `repository.url` before publishing.
